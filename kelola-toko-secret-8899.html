Izin Simpan ke Supabase

Supabase mengamankan basis data dengan Row Level Security (RLS). Untuk mengizinkan modifikasi data hanya kepada Owner terotentikasi, jalankan skrip keamanan ini di Supabase SQL Editor: 

-- Hardened RLS Policy (Authenticated Owner Only)
revoke insert, update, delete on products, site_config, categories from anon;
grant select on products, site_config, categories to anon, authenticated;
grant insert, update, delete on products, site_config, categories to authenticated;

create policy "Authenticated insert: products" on products for insert to authenticated with check (true);
create policy "Authenticated update: products" on products for update to authenticated using (true) with check (true);
create policy "Authenticated delete: products" on products for delete to authenticated using (true);
create policy "Authenticated update: site_config" on site_config for update to authenticated using (true) with check (true);
